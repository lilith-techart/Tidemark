### Technical pass ≠ visual pass

Mesh manifold checks, Blender/FBX re-imports, camera parity, and protected hash regression verify engineering properties. None prove geological naturalism or Human Art approval.

### Candidate retained ≠ canonical promotion

The latest retained **visual candidate** is G012. Later studies G014–G016.1 did not overwrite it. Canonical promotion remains absent.

### Walkable surface ≠ visual ground

The project's inherited G004 collision route can be regression-tested without certifying new visual terrain or visual stairs for gameplay. This archive never describes the experimental rocks as gameplay-ready.

### Screenshots vs schematics

Only the existing G012 cover in this archive is a real publicly hosted UE capture. SVGs here are human-readable diagrams of documented outcomes. Governed real Blender comparison screenshots exist locally, but their exact pixels are not mirrored by this commit.

### Publication boundaries

No complete Unreal Engine project, private filesystem layout, authentication details, agent runtime logs, unknown-license source assets, or external concept art is included. Existing public files have **not been updated or removed**.
