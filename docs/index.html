03 / TECHNICAL ART

把“看起来正确”
拆成可以验证的问题。

技术研究摘要 ↗
01

连续网格与拓扑

在锁定规划约束下构建真实网格，检查连通分量、退化面、非流形边、法线与体积。有限自交检测保留其覆盖边界，不宣称严格数学证明。

Implemented in task-specific scripts
02

规划接触采样

每个岩核候选记录 511 个规划接触采样。采样通过只表示这些位置的几何关系，不等于真实建筑整体承载、碰撞或可行走认证。

Historical measured evidence / scoped
03

落盘，而不只在内存中

独立 Blender 进程从磁盘重载，核对几何签名与场景对象，再输出原八机位。截图、日志和技术状态一起归档；技术通过不代替人工美术审查。

Fresh reload / multi-camera evidence
Human Design→Candidate Geometry→Technical QA→Visual Evidence→Human Review→UE Integration

前四项已有局部研究证据；R5 聚落组合与独立重载已完成，建筑与路线仍为研究候选。Human Art 尚待验收，UE 集成未执行。Agent 不拥有最终美术批准权。
