# Tidemark · 程序化海岸聚落与实时环境技术研究

## 一分钟介绍

我在做一个灯塔海岛聚落的数字空间研究。它不只是把房子摆在岛上，而是研究岩体、建筑高差、登陆路线和海面留白怎样形成可信的整体。我用 Unreal Engine 做实际场景研究，用 Blender 和 Python 制作受设计约束的连续岩核，并通过几何检查、独立重载和固定机位对照确认真实结果。项目还没有完成最终美术，当前价值在于把设计迭代和技术证据连起来：既看画面，也知道哪些判断已经验证、哪些还需要人工审查。

## 三个技术亮点

- **设计约束与生成协作：** 锁定规划位置、尺寸、标高和路线，不让程序任意重排。
- **独立验证：** 保存后用新进程重新打开、核对几何，再比较同机位画面。
- **失败可追溯：** 保留差的角度；技术通过不代替美术审查，不合格结果不晋级。
