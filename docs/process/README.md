The new SVG figures are **original explanatory drawings based on the project reports**, not Blender meshes, Unreal screenshots or reference-art reproductions. The G012 image is a real existing public UE capture. The original G014–G016.1 detailed comparison screenshots remain in the project's governed evidence set and **are not yet included as new public raster files in this first additive update**. ### What a reviewer should learn

A reliable environment workflow is not measured by how many generated assets survive. G016.1 kept exact source/provenance and technical checks, **rejected both weak art candidates**, and preserved the last retained G012 scene.
