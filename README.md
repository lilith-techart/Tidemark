# Tidemark

**Unreal Engine 5 Environment Art & Technical Art Project**

> A portfolio-focused real-time environment project exploring modular production, reusable technical-art workflows, materials, scene construction, and production-oriented tooling.

---

## Overview

**Tidemark** is an Unreal Engine 5 environment / technical art project developed as a long-form portfolio piece.

The project is not only about producing a finished scene. Its main goal is to build and document a reusable workflow for turning visual reference and whitebox decisions into a structured, production-ready environment.

### Primary goals

- Build a convincing real-time environment in Unreal Engine 5.
- Develop a modular asset workflow that supports iteration instead of one-off modeling.
- Improve the handoff between blockout, environment art, materials, tooling, and final presentation.
- Record technical decisions and breakdowns clearly enough to be reviewed as Technical Art work.
- Keep useful systems reusable for future projects rather than locking them to one scene.
